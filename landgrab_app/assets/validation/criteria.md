# What to check

**If you’re short on time, prioritise confirming puzzlets over poles.** Poles can
be confirmed during arbitrary hours, whereas puzzlets should be confirmed
during the window of the adventure, to align with building access patterns.

To validate a puzzlet or pole, you can:

- say ”this worked for me”
- add corrections and suggestions
- mark that you couldn’t find it

## Puzzlets

When a player is presented with the description, can they find the answer?
Some amount of crypticness is good, but is it too much?

- **locations are not shown to players**, so the description is what’s important
- try submitting the answer, but it can be revealed if you can’t find it or it’s saying it’s wrong
- are there accessibility concerns that are missing?
- “difficulty” is a subjective rating but does it seem reasonable?
- some are grouped by building or area of a building
  - each puzzlet in such a group will duplicate the shared access description
  - if you need to correct any shared information, do it on one of the puzzlets

## Poles

Players will see poles on a map but not know any more than that. There may be more than one
pole in an area, so some amount of trial-and-error is expected, but we do want the location
on the map to match the location of the pole.

**During data collection, some pole locations were pretty off, so fixing that is helpful.**
The map shows the uncertainty of the location reading.

- can you find the pole at the location shown?
- are you able to scan the barcode and it matches?
- are there accessibility concerns that are missing?
